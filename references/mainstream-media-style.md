# 主流媒体风格详解

## 上海证券报

### 媒体定位
由新华社主办，中国证监会指定披露上市公司信息的权威财经媒体。

### 风格特点
- **权威性**：使用官方表述，严谨规范
- **倒金字塔**：核心信息前置
- **数据支撑**：关键陈述必须有数据支撑
- **政策关联**：关联监管政策和行业背景

### 标题风格
- 正式、完整信息
- 主标题≤20字
- 示例：《盈米基金与阿里云达成AI全栈战略合作》

### 字数建议
- 800-1500字（标准稿）
- 导语100字内

### 写作禁忌
- ❌ "重磅"、"震撼"、"曝光"
- ❌ "首次"、"首创"（无事实依据）
- ❌ 网络用语、口语化表达

---

## 证券时报

### 媒体定位
深度报道、行业分析、专业解读的财经媒体。

### 风格特点
- **深度分析**：可展开背景分析
- **专业性强**：突出行业价值
- **数据详实**：详细的数据支撑

### 标题风格
- 专业性强、突出价值
- 主标题≤20字
- 示例：《AI+财富管理新生态：盈米基金联合产业链共建基础设施》

### 字数建议
- 1500-2500字（深度稿）

---

## 财联社

### 媒体定位
24小时财经新闻平台，快速资讯、简洁明了。

### 风格特点
- **快速资讯**：核心信息前置
- **简洁明了**：开门见山
- **短促有力**：句式简短

### 标题风格
- 短促有力（≤15字）
- 关键信息前置
- 示例：《盈米基金与阿里云达成AI战略合作》

### 字数建议
- 600-1000字
- 导语50字内

---

## 通用写作规范

### 导语公式
```
[时间] + [主体] + [事件] + [核心信息]
```

### 数据引用
```
[数据] + [来源] + [截止时间]
```

示例：
- "盈利客户占比92%（截至2025年12月）"
- "同比增长150%，去年同期为..."

### 常见问题
| 问题 | 正确做法 |
|------|----------|
| 重复论述 | 同类信息合并为一段 |
| 修饰语过多 | 删除"全面的"、"深入的" |
| 小点列表 | 用流畅段落替代 |
| 表格滥用 | 能用文字表达的优先用文字 |
