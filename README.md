# 新闻编辑 Skill (news-editor)

## 简介

专业的新闻稿润色编辑工具，将已有新闻稿优化为符合**上海证券报、证券时报、财联社**等权威主流媒体标准的专业稿件。

自动识别并修复六大写作硬伤，提升新闻稿专业度和发表率。

---

## 核心功能

### 编辑能力

| 功能 | 说明 |
|------|------|
| **润色优化** | 提升语言专业度，删除空泛修饰 |
| **起新闻标题** | 符合媒体风格的标题优化 |
| **硬伤修复** | 自动识别并修复六大写作硬伤 |
| **结构调整** | 倒金字塔结构重组 |
| **行业高度提升** | 从企业视角上升到行业视角 |

### 六大硬伤自动检查

1. **大白话过多** → 自动转换为专业表述
2. **信息重复** → 删除重复内容
3. **逻辑不严谨** → 添加过渡句
4. **没有主线贯穿** → 提炼核心主线
5. **缺乏理论高度** → 增加行业洞察
6. **过渡生硬** → 平滑段落衔接

---

## 核心编辑原则

| 原则 | 具体操作 |
|------|----------|
| **删冗余** | 删除"全面的"、"深入的"等空泛修饰语 |
| **合并同类** | 同类信息合并为一段 |
| **数据优先** | 核心观点用数据支撑 |
| **增量突出** | 优先保留"新增"、"升级"等增量信息 |
| **格局提升** | 从企业视角上升到行业、政策、趋势视角 |

## 新闻稿编辑标准

### 字数控制

| 媒体类型 | 建议字数 |
|----------|----------|
| 上海证券报 | 3000-4000字 |
| 财联社 | 1500-2500字 |
| 证券时报 | 2000-3000字 |
| 钛媒体 | 2500-3500字 |

### 结构要求

- **导语**：时间、事件、主体、意义（1段）
- **主体**：详情、背景、观点、展望（3-5段）
- **结尾**：公司介绍、媒体联络（1段）

### 标题规范

- 上海证券报：中性客观，20字以内
- 财联社：简洁有力，15字以内
- 钛媒体：突出科技感，20字以内
